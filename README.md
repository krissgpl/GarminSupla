# GarminSupla

GarminSupla is a bridge between Garmin Connect IQ devices and the SUPLA REST API.

## Features

- Open gate
- Close gate
- Gate status
- OAuth2 authentication with SUPLA
- REST API for Garmin Connect IQ

🚧 In development

## Requirements

- Docker
- Docker Compose
